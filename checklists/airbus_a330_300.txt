# XChecklist-style normal checklist for the X-Plane 12 stock Airbus A330-300.
# Written 2026-09-20 for XVoiceLayer from the aircraft's own Pilot Operating
# Manual (pp.55-84, the only checklists it prints), its xlua auto-board /
# auto-start sequences (A333.Z.autostart.lua) and an audit of which stock
# datarefs its scripts rewrite every frame. Every test below reads a dataref
# the aircraft OWNS or leaves alone: the stock seat-belt, transponder-mode,
# battery, generator, bleed, pack, pump and strobe/nav datarefs are all
# DERIVED per frame from the laminar/A333 switch positions, which makes them
# honest READS (they say what the aircraft is doing) even though a write to
# them is a silent no-op. Section titles are the crew's phase keys, so the
# tracker proposes each list at its phase. Items with no test are call-outs.
# An item conditioned on a height the list does not run at is a call-out.
