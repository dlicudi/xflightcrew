# XChecklist-style normal checklist for the X-Plane 12 stock Boeing 737-800.
# Written 2026-09-17 for XVoiceLayer from the aircraft's own Pilot Operating
# Manual, its xlua auto-start sequence (B738.Z.autostart: the steps Laminar's
# own script performs) and the community Laminar-737 list by ch4dwick
# (github.com/ch4dwick/xplane-12-checklists). Every dataref below was checked
# to EXIST on the stock aircraft over the Web API that day. Section titles are
# the crew's phase keys, so the tracker proposes each list at its phase.
# Conditions are single dataref tests; items with no test are call-outs.
# An item conditioned on a height the list does not run at (landing lights
# off above 10,000 in a climb list that runs at 2,000 ft; QNH to standard at
# the transition; landing lights on below 10,000 in a descent list that runs
# at the top of descent) is a call-out: the crew's own lights law and
# altimeter check own those switches at the right height, and a test here
# was a guaranteed "not set" on every flight (LFLL-EGLL, 2026-09-17).

sw_item:FUEL PUMPS CENTER|ON:sim/cockpit2/fuel/fuel_tank_pump_on[1]:1
sw_item:FUEL PUMPS RIGHT|ON:sim/cockpit2/fuel/fuel_tank_pump_on[2]:1
sw_item:APU BLEED|ON:sim/cockpit2/bleedair/actuators/apu_bleed:1
sw_item:PACKS|AUTO:sim/cockpit2/bleedair/actuators/pack_left:1

sw_checklist:BEFORE START:BEFORE START
