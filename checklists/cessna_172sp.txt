# Cessna 172SP checklists — x-copilot curated edition.
#
# Format: XChecklist (.txt), so community files for other aircraft load too.
# Source/structure derived from KarlL's "Cessna 172SP Streamlined Procedures
# for X-Plane" (v1.2, for the XChecklist plug-in) — credit to KarlL. The
# procedure sequences are his; we re-authored the file and CORRECTED the verify
# datarefs to the ones x-copilot's tools actually drive, so that when the copilot
# offers to fix a failed item the re-read confirms it. Notable changes from the
# original: lights verify via sim/cockpit2/switches/* (not sim/cockpit/electrical/*),
# engine actuators via *_ratio_all (not [0]), pitot via cockpit2/ice/*, parking
# brake via parking_brake_ratio, autopilot via servos_on, transponder via
# cockpit2/radios/actuators/transponder_mode. Non-simulated steps stay in
# [brackets] as spoken context.
#
# COND grammar: N (equals) | >N | <N | !N (not-equals) | LO|HI (inclusive range).
#
