# Cirrus Vision SF50 - transcribed from the Checklists section of
# X-Plane_SF50_Pilot_Operating_Manual.pdf (p.40-60), which ships inside the
# aircraft folder. Those pages are IMAGES, not text, so this is a hand
# transcription of the rendered pages rather than an extraction.
#
# The POM states its own scope up front: "The following check list is a sub-set
# of the real procedures, and includes only the essential steps leading to
# engine start." Everything below is exactly what those pages show, in their
# order, and nothing has been invented to fill it out.
#
# ONE deliberate omission. The POM's Before Taxi has "TAXI LIGHTS - ON" and its
# Parking has "TAXI LIGHTS - OFF", but this aircraft has no taxi light: the
# cockpit object carries exactly three light manipulators (Navigation lights,
# Landing lights, Strobe lights) and sf50_lights.lua finds exactly those three
# switches. The POM reuses one generic cockpit photograph for the nav, landing
# and taxi rows, and the taxi one points at a switch the model does not have.
# A copilot calling for a light that cannot be switched is worse than a
# checklist that is one line shorter, so the rows are dropped and recorded here.
#
# Datarefs are all stock - this airframe's xlua replaces no commands and drives
# every system below through X-Plane's own datarefs.
